# CPU F32 direct comparison — 2026-08-12

## Result

On the Ryzen 9 9950X with 16 benchmark threads, the Rust DA3-BASE-F32 path
was faster than the matching C++/ggml path:

| Runtime | Mean of 10 independent trial medians | 95% CI | Trial-median SD |
|---|---:|---:|---:|
| Rust | 208.889 ms | [206.109, 211.668] ms | 3.886 ms |
| C++ / ggml | 241.203 ms | [240.300, 242.107] ms | 1.263 ms |

Rust is 13.40% faster: `(241.20325 / 208.8886 - 1) * 100`.
The confidence intervals do not overlap.

## Locked workload

- Model: `depth-anything-base-f32.gguf`, SHA-256
  `1b13b166e8a8b4f2c862f42d36edb2f9aab995a18cc527a52b9f160b99c6b8da`,
  412,110,144 bytes.
- Image: `mountains.jpg`, SHA-256
  `936d60f43c51fe99156563a0d3c5da69cf84a39cbde5e443bea7662500b8c969`.
- Resize: 504×336. Decode and model load excluded; preprocessing, backbone,
  depth/confidence head and postprocessing included.
- Every trial: fresh process, one warm-up, ten timed iterations. Ten trials
  per arm; randomised arm order, seed `20260812`, three-second cooldown.
- Rust build: `RUSTFLAGS="-C target-cpu=znver5"`; runtime environment
  `RAYON_NUM_THREADS=16`. The C++ arm received `--threads 16`.
- Host: Linux 7.1.5, AMD Ryzen 9 9950X, 32 logical CPUs, 91 GiB RAM.
