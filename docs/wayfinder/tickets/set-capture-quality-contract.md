# Set the capture and quality contract

Label: `wayfinder:grilling`

## Question

What observable capture requirements and measurable output gates make a normal RGB walkthrough dependable enough for an MVP with metric 3D and 2D exports?

## Resolution

Closed — the user delegated approval of the recommended contract, recorded in
[the source-backed capture and quality contract](../research/capture-quality-contract.md).

Final exports require a connected, looped, well-overlapped walkthrough and
hard registration/reprojection/coverage gates. A primary anchor sets scale;
an optional independent anchor is required for the `verified` status.
